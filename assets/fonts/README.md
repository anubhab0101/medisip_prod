# Embedded PDF fonts

Noto Sans, Noto Sans Devanagari and Noto Sans Oriya (Regular and Bold), unmodified.
Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf
License: SIL Open Font License 1.1, included in LICENSE.txt.

These files are bundled with the application. PDF generation makes no external font requests and supports English, Hindi and Odia text runs.
PDF layout API: https://pdfmake.github.io/docs/0.3/getting-started/server-side/
